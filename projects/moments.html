Case study 05 Real-time product

Moments

A real-time event platform: guests share photos by scanning a QR code, and hosts curate a live gallery.

Type
Product design & build
Platform
Web · staff mobile concept
Stack
Next.js, TypeScript, Supabase, PostgreSQL
Focus
Real-time, auth, data isolation

01

The problem

At events, the best photos are spread across a hundred phones — and nobody wants to install an app to share them.

Hosts want those moments in one place, live, without losing control over what appears on screen.

02

My responsibility

  • 01Product architectureDesigned the event workflows across guests, hosts and staff.
  • 02Guest flowQR-based photo upload from the mobile web, with no app install.
  • 03Real-time galleryLive gallery updates and the moderation workflow behind them.
  • 04Access & isolationAuthentication, roles and per-event data access.

03

The architecture

Guests
qr code → mobile web uploadno app install
Application · Next.js
host dashboardmoderation queuelive galleryanalytics
Supabase
authpostgresqlstorage · mediarealtime

Uploads land in storage with their metadata in PostgreSQL. Changes stream to the live gallery in real time, and hosts approve or hide media from the moderation queue. Every record belongs to exactly one event.

04

Engineering challenges

01

Zero friction for guests

Uploading has to work from a QR scan in seconds, on any phone.

02

Live, but moderated

Photos should appear quickly — but the host decides what is shown.

03

Isolation between events

One host must never see another event's guests or media.

04

Bursty media

Many uploads arrive at the same moment, right when the event peaks.

05

The solution

  1. QR to uploadEach event has its own QR code that opens a mobile web upload flow — no app required.
  2. Event-scoped dataEvent data is scoped and protected per event, with authentication for hosts and staff.
  3. Real-time galleryApproved media streams to the gallery as it arrives.
  4. Moderation & analyticsHosts manage media, work the moderation queue and follow event activity from a dashboard.

07

Outcome & lessons

Real-time products only feel simple when the data model, permissions and failure states are designed together.

  • Decide who can see what before deciding how fast it appears.
  • Moderation is a product feature, not an admin afterthought.
  • The guest path deserves the most polish — it is the one used most.
