CRM Panel

A web-based CRM and appointment system for service businesses — bookings, session usage, communication and activity tracking in one place.

Type
Full-stack web application
Users
Admins, managers, clients
Stack
React, Node.js, MongoDB
Interface
Hebrew (RTL)

01

Overview

Service businesses need one place to manage bookings, monitor session usage and keep clients informed.

  • Slot-based calendar with per-session participant limits
  • Admin dashboard with client, appointment and booking statistics
  • PDF, CSV and Word exports for reporting
  • Email notifications and WhatsApp API integration for appointment reminders
  • Real-time updates with Socket.IO
